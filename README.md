## Sistema de Biblioteca
## Descrição
O sistema web é para o gerenciamento de livros, autores, leitores e empréstimos.
## Tecnologias que foram utilizadas no projeto:
- Flask
- Flask-SQLAlchemy
- Python
- SQLite
- HTML e CSS
## As funcionalidades que foram usadas no projeto:
- Cadastro de autores, livros e leitores.
- Registro de livros e devolução.
- Edição e remoção de livros.
- Consultar o histórico de hipopréstimos.
## Como executar o projeto:
- 1. Instale as pendências com pip install -r requirements.txt.
- 2. Execute python seed.py para cadastrar os dados.
- 3. Execute python app.py para iniciar o sistema.
- 4. Acesse o http://127.0.0.1:5000/ no navegador web.
